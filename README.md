# Kanakk Book Website

Static GitHub Pages website for the Kanakk Book app.

## Before publishing
1. Open `index.html`.
2. Replace the Google Play button `href="#"` with the real Play Store URL.
3. Review `privacy-policy.html` and `terms.html` against your final app behavior and third-party SDKs.
4. Upload the whole folder to a GitHub repository and enable GitHub Pages from the repository's Settings > Pages.
